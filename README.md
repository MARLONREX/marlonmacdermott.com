# MacDermott Designs website

This folder is the website root. Keep index.html at the repository root.

WEB projects were copied into project-content/<project name>/, organised as Image1, Image2, etc., Body of text, and Documents. The original WEB folder was preserved.

Open index.html to browse the gallery. Open files.html to browse and filter the website files.

New project pages are static HTML and work without a Python server. Legacy project.html pages use project-data/*.json when served over HTTP, including GitHub Pages.

To prepare a GitHub Pages deployment, commit the contents of this folder to the intended repository and select its publishing branch/root in GitHub Pages. Nothing has been uploaded or published by this task. Preserve CNAME only if dermottdesign.com is the intended custom domain.

The project contains large image assets. Use Git to upload the repository. No individual file exceeded 100 MB at preparation time.

The four text-only projects are Hawthorns, Hazelwood, MAup 1 and MAup 4. Images can be added later.
